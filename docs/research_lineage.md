# Research lineage

This repository is a clean reimplementation, not a fork or rewrite, of ideas observed in the following read-only research artifacts:

- `agentCoder` / `agent_coder`: agent decomposition and code-generation workflows.
- `multi-agent-react-sandbox`: multi-agent generation plus isolated execution feedback; fallback behavior is intentionally rejected here because scientific evaluation must fail closed when the sandbox is unavailable.
- `CodeChain`: controlled sequential refinement, objective execution, and compute accounting.
- `Reasoning-Agent`: agentic reasoning patterns; implementation details are not copied without methodological review.
- `LLM_reasoning_solve_NQueen_with_no_code`: prompt-time iterative refinement and verifiable discrete tasks.
- `Reasoning-Is-All-You-Need`: candidate generation, objective selection, and execution-based debugging.
- `efficient-reasoning-research`: fixed budgets, immutable benchmark provenance, seed control, manifests, result schemas, auditability, and statistical analysis.

The predecessor repositories remain READ-ONLY. This project reimplements concepts behind common interfaces rather than copying source trees.
